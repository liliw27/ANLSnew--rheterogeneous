# Legacy notes（历史遗留实现备注）

本文档用于存放**主线代码之外**的历史遗留实现信息，目的是：

- 让主流程代码更短、更聚焦（更便于阅读与维护）
- 同时保留“为什么当年这么写”的上下文，便于后续追溯

---

## 1. `SimulatedAnnealing.run()` 末尾被移除的大段统计代码

在早期实验版本中，`SA/SimulatedAnnealing.java` 的 `run()` 方法末尾包含数百行“注释掉的统计/打印代码”，主要用途是：

- 统计每个算子在迭代进程中被使用的分布（按 1% 或 10% 分箱）
- 统计“产生 best solution”的迭代位置分布
- 导出每个 segment 的算子权重轨迹（`weight` 列表）以便画图

这段代码长期处于“注释状态”，噪音很大、也容易误导读者把它当作核心逻辑，因此已从主文件删除。

如果你确实需要恢复它：

- **首选**：从 git 历史里找回对应提交（保留原样最安全）
- **次选**：在 `testSA.java` 中用更清晰的方式重写统计（建议拆成独立 `StatsCollector` 类）

---

## 2. 建议的现代化做法（如果未来要重新做统计）

- **不要把统计逻辑写在 `SimulatedAnnealing.run()` 里**：改成独立类（例如 `StatsTracker`）
- **输出结构化数据**：优先 CSV/TSV/JSON，而不是拼大字符串
- **只记录必要指标**：例如每个 segment 的 weight、每个算子在 segment 内的 usedNum/score
